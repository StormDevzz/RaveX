### Building

#### Recommended Windows environment

The recommended build environment for Windows is:

* Windows 10 21H2 or 22H2, or Windows 11
* Visual Studio 2022 with **Desktop development with C++**
* MSVC v143 and Windows 10 SDK 10.0.19041.0 or newer
* CMake 3.25 or newer
* JDK 21 x64, including `javac` and JNI headers
* x64 build tools

Run the native build from **Developer PowerShell for VS 2022**:

```powershell
cd C:\path\to\RaveX
.\build_windows.bat
```

Administrator privileges are not required for compilation. The build uses MSVC x64 and targets the Windows 10 21H2 API level. MinGW is not the supported Windows build profile.

The script configures native files in `build/native-msvc`, runs the native DLL smoke tests, and then builds the Java project. Native DLLs are written to `src/main/resources/assets/ravex/natives`.

#### Linux environment

Linux native libraries can be built with the dependencies described in `build_linux.sh`. The Java build still requires JDK 21.

#### Java-only build

```bash
./gradlew build
```

The built JAR will be in `build/libs/`.
Pre-built JARs are also available in the Releases section.

### Verification

Every release automatically publishes SHA-256 checksums so anyone can verify what they download:

* Each release contains a **`SHA256SUMS.txt`** asset with hashes of all published files (RaveX JAR, `KickXSetup.exe`, `kickx_launcher.exe`, launcher archives).
* The release description contains a generated table with **SHA-256 hashes and direct VirusTotal links** for the KickX Launcher and the RaveX client.

Check a downloaded file:

```powershell
# Windows (PowerShell)
Get-FileHash .\KickXSetup.exe -Algorithm SHA256
```

```bash
# Linux
sha256sum -c SHA256SUMS.txt
```

Compare the result with `SHA256SUMS.txt` or with the table in the release description, then open `https://www.virustotal.com/gui/file/<your-hash>` to scan the file with 70+ antivirus engines.

This project is fully open source. Anyone can build the jar from source and verify the client contains no malicious code:

```bash
git clone https://github.com/StormDevzz/RaveX.git
cd RaveX
./gradlew build
```

If you don't trust the binary - check its hash against the release, or build it yourself.

### Native libraries

RaveX ships its C++ libraries inside the JAR and unpacks them on demand into `~/.ravex/natives` (the path is the same on every OS).
That folder also works as an override location:

* Drop your own build of `ravex_<name>.dll` (`libravex_<name>.so` on Linux) into that folder and the mod loads it as is, even when its hash is not the bundled one.
* Handy for testing native changes without rebuilding the whole mod: rebuild one CMake target, copy the file over, restart the game.
* Delete the file and the bundled build is unpacked again.
* `README.txt` and `.ravex-extracted.txt` are created by the mod itself. The second one records what it unpacked, those files are refreshed automatically when the bundled build changes.
* Bundled libraries are verified by SHA-256 before loading, custom files are used as they are, so only put files there that you trust.
* While the game runs you can see the `RaveX Native Manager` process in the task manager, it appears only when the native layer is up.

* В описании релиза генерируется таблица с **SHA-256 хешами и прямыми ссылками на VirusTotal** для KickX лаунчера и клиента RaveX.

Сравни результат с `SHA256SUMS.txt` или с таблицей в описании релиза, а затем открой `https://www.virustotal.com/gui/file/<твой-хеш>` - файл просканируют 70+ антивирусных движков.

### Нативные библиотеки

RaveX хранит свои C++ библиотеки внутри JAR и распаковывает их по требованию в `~/.ravex/natives` (путь одинаковый на всех системах).
Эта папка работает ещё и как папка переопределений:

* Положи туда свою сборку `ravex_<имя>.dll` (`libravex_<имя>.so` на Linux), и мод загрузит её как есть, даже если хеш не совпадает с официальным.
* Удобно тестировать правки в нативном коде без полной пересборки мода: собери одну CMake-цель, скопируй файл, перезапусти игру.
* Удали файл, и официальная сборка распакуется заново.
* Файлы `README.txt` и `.ravex-extracted.txt` создаёт сам мод. Второй хранит список того, что он распаковал, такие файлы обновляются автоматически при смене официальной сборки.
* Официальные библиотеки проверяются по SHA-256 перед загрузкой, свои файлы используются как есть, поэтому клади туда только то, чему доверяешь.
* Пока игра запущена, в диспетчере задач виден процесс `RaveX Native Manager`, он появляется только когда нативный слой поднялся.
