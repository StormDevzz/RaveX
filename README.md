## EN

RaveX is an open-source Minecraft client modification by StormDevzz organization.

### Languages in this project

| Language | Purpose |
|---|---|
| **Java** | Core mod logic - ClickGUI, modules, mixins, rendering |
| **C++** | Native code for performance-critical operations: optimizer, anti-AFK, shader hooks, JNI bridge |
| **Lua** | Scripting - rich presence, Discord integration, custom modules and Lua addons |
| **Makefile** | Generated by CMake for building C++ components (native libraries) |

### Building

```bash
./gradlew build
```

The built JAR will be in `build/libs/`.
Pre-built JARs are also available in the Releases section.

### Verification

This project is fully open source. Anyone can build the jar from source and verify the client contains no malicious code:

```bash
git clone https://github.com/StormDevzz/RaveX.git
cd RaveX
./gradlew build
```

The sha-256 hash of your local build will match the official release hash given the same code version. If you don't trust the binary - build it yourself.

### Installation

1. Install Fabric Loader
2. Place the JAR in your `mods` folder
3. Launch the game

### Сборка

```bash
./gradlew build
```

Готовый JAR находится в `build/libs/`.
Готовые сборки также доступны в разделе Releases.

### Верификация

Этот проект полностью с открытым исходным кодом. Любой желающий может самостоятельно собрать jar из исходников и убедиться, что клиент не содержит вредоносного кода:

```bash
git clone https://github.com/StormDevzz/RaveX.git
cd RaveX
./gradlew build
```

sha-256 хеш твоей локальной сборки будет совпадать с хешем официального релиза при условии одинаковой версии кода. Если сомневаешься в бинарнике - собирай сам.
